# Real Metabolism v3 · 核心竞争力与玩家动因分析

- 日期：2026-09-23
- 依据：v3 设计文档、技术文档、API 审查报告
- 用途：产品定位 / Wiki / 对外介绍

---

## 一、核心竞争力（PZ MOD 生态视角）

### 1. 单 MOD 三系统耦合：市面上几乎没有竞品做全

大多数 PZ 营养类 MOD 只做**单一子系统**（要么只加微量营养、要么只改运动消耗、要么只做环境温度）。v3 把**营养 / 运动 / 环境**做成三个平级子系统共享一个"代谢核心"，形成 5 条跨系统因果闭环：

- **闷热作战**：高湿高温 → 狂出汗 → 水合↓+钠钾↓ → 先脱水（喝水可解）→ 继续则低钠抽搐（补盐）→ 体温失控中暑
- **罐头经济**：罐头稳定供热量/矿物质但 VC 降解为零 → 长期只吃罐头 → 坏血病；新鲜蔬果（冷藏/采集）是解
- **训练日**：高强度训练 → 碳水消耗+负荷累积 → 窗口内补碳水+蛋白+睡觉 → 超量恢复涨经验；空腹硬练 → 恢复债 → 过度训练
- **雨后赶路**：湿衣+低温 → 热量消耗放大 → 空腹时脂肪/蛋白被动用、体重下降 → 长期叠加消瘦病
- **啤酒误区**：拿啤酒当水 → 利尿净脱水 + 空热量 + 醉酒失温风险

**竞争力**：一个订阅解决"吃/动/环境"三个维度，且三者互相影响，不是简单叠加。

---

### 2. "调制层，不做第二套引擎"——工程可靠性是护城河

v3 技术文档经 Zombie Atlas 反编译核实后确立的硬边界：

| 原则 | 工程含义 |
|---|---|
| 读原生、不接管 | 体重/体温/酸痛/经验门控走原版逻辑，MOD 不重算 |
| 宏量池只读、不硬写 | 禁止每秒 `setCalories/setWeight`；引擎无外部倍率挂点 |
| 燃料只记 MOD 台账 | 强度×时长×空腹得出的碳水/脂肪/蛋白比例只供 UI/成长/疾病/仿真，不重定向原生消耗 |
| 耐力走原生修饰接口 | 统一惩罚归一化 clamp ±20%，防属性爆负 / NaN |

**竞争力**：这避免了 PZ 营养 MOD 最常见的死因——**双重计算导致体重/体温/经验紊乱、与其他 MOD 冲突、存档损坏**。v3 的边界设计使它能和绝大多数 MOD 共存。

---

### 3. 生理因果优先：每个效果都能回答"因为身体发生了什么"

- 冲刺不消耗维生素（微量不进动作消耗）
- 啤酒不能真正解渴（利尿净脱水 + 空热量）
- 纯水补大量出汗后水合正常但血钠低 → 电解质紊乱（治疗靠咸食不是灌水）
- 维C降解最快，罐头经济制造坏血病压力

**竞争力**：不是"加数值"，而是"讲生理逻辑"。玩家能推理出因果，而不是背数值表。

---

### 4. 连续池 + 阶梯状态机的双时间尺度

| 时间尺度 | 机制 | 例子 |
|---|---|---|
| 分钟级连续池 | 水合 0–100、能量反馈 0–1、核心体温 | 脱水阈值、急性事件 |
| 多日阶梯状态机 | 7 天均值 < 阈值连续 N 天 → 潜伏/轻/中/重 | 7 种营养病 4 阶段 |

**竞争力**：短期有即时反馈（口渴、中暑），长期有经营压力（坏血病、消瘦），避免了"要么太琐碎要么太抽象"的极端。

---

### 5. 数据驱动 + 沙盒可关

- 全部系数集中 `RM_Config.lua`（DRI/TDEE/燃料曲线/降解/饮品/疾病/环境/图标）
- SandboxVars 暴露：疾病速率、消耗倍率、环境严酷度、降解速率、水合严格度、单病/单事件开关、日照产 D

**竞争力**：硬核玩家拉满严酷度，休闲玩家关掉疾病只留水合，不强迫单一玩法。

---

### 6. NeatUI 适配层隔离 + Vanilla-Native 视觉

- NeatUI 只出现在 `RM_UIAdapter.lua`，业务代码零依赖；停更时重写适配层即可
- 米色纸感、深棕描边、原版位图字体、色盲三重编码——和原版 moodle 风格统一
- Nutritionist trait 控制毫克精度，无 trait 只看定性档（沉浸感 + 特质价值）

## 二、不同类型玩家为什么要加这个 MOD

### 🎮 生存硬核玩家

**痛点**：原版生存威胁只剩僵尸，吃饱了就无敌。

**v3 给的**：水合、中暑、失温、坏血病、贫血……威胁从"外部僵尸"扩展到"内部身体"。雨季湿衣赶路、长期吃罐头、高温战斗都可能致命。生存目标从"活到第 N 天"变成"维持一个健康的身体"。

---

### 🧪 拟真/模拟玩家

**痛点**：原版营养只有热量+4 宏量，太浅；没有水合、没有微量、没有疾病因果。

**v3 给的**：8 种微量营养素 + DRI、7 种缺乏病、底物燃料切换、蛋白合成窗口、日照产维 D。接近真实生理仿真，"生理人"长周期跑 30–60 天能验证行为。

---

### 🛒 经营/策略玩家

**痛点**：原版食物策略只有"保质期"一个维度。

**v3 给的**：
- 罐头 vs 新鲜蔬果的 VC 取舍（必须经营新鲜食物供应链）
- 冷藏 ×0.3 / 冷冻暂停 / 罐头锁定
- 训练后 4 小时蛋白窗口的时间管理
- 高温高湿下的钠钾补给策略

---

### 💪 养成 / Min-Max 玩家

**痛点**：原版 Fitness/Strength 就是肝锻炼，没有恢复概念。

**v3 给的**：训练负荷→恢复质量→超量适应→经验放大；连续高负荷恢复不足→过度训练（成长打折、疲劳加速）；空腹硬练=白练。**练+吃+睡**三位一体，规划性变强。

---

### 🎭 沉浸 / RP 玩家

**痛点**：原版没有"身体状态"的叙事层。

**v3 给的**：自定义角落状态图标（7 病四阶段 + 脱水/中暑/失温/低钠/醉酒/咖啡因/过度训练），早期疾病给模糊图标+症状体感，病名要进面板才看得到；无 Nutritionist trait 只看定性档。沉浸感保留，不喂数值。

---

### 🍺 好奇心 / 梗玩家

**痛点**：原版啤酒就是另一种水。

**v3 给的**：拿啤酒当水→利尿净脱水+空热量+醉酒+失温风险上升。咖啡短时抗疲劳但之后疲劳反弹。这些"反直觉但符合生理"的机制制造话题和梗。

---

### 👥 兼容性敏感玩家（爱装一堆 MOD 的）

**痛点**：营养类 MOD 容易和体重/体温 MOD 冲突，双重计算把数值搞崩。

**v3 给的**：只读原生状态、不接管引擎逻辑、修饰器可重算纯派生（摘除即还原）、酒精走原生醉酒机制（去重防双计）。和绝大多数 MOD 共存，不破坏存档。

---

## 三、一句话定位

> **一个不越界的生理仿真层**——把"吃什么、怎么动、在什么天气待着"做成有因果、有前兆、可逆、有解的身体经营，同时不破坏原版的体重/体温/经验系统。

这是 v3 相比同类 MOD 最核心的差异点：**做得多，但守得住边界**。
