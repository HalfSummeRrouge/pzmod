# Real Metabolism v3 · M4 数值平衡规格

> **文档性质**：M4 阶段数值调优的目标规格。因果逻辑以设计/技术文档为准，本文规定"每个数值要调到什么体感、用什么方法验证"。
> **版本**：v3 · 2026-09-23
> **前置**：设计文档 §10（测试与调参）、技术文档 §9（数据流）

---

## 1. 设计原则

```
现实 → 定因果（为什么）
游戏 → 定体感（多快、多狠、多爽）
```

- **因果必须真实**：啤酒利尿、VC 防坏血病、练完补蛋白有效——玩家能推理。
- **数值必须调过**：纯现实 DRI 是为"98% 健康人群不缺"设计的，不是为"制造游戏压力"设计的，直接用会导致营养系统形同虚设。
- **压力 + 正反馈双轨**：不发病只是底线，吃好/练好必须有明显爽感。

## 3. 目标体感定义

### 3.1 压迫感（Pressure）

| 系统 | 体感目标 |
|---|---|
| 营养 | 不能靠罐头躺平，必须经营新鲜食物；约 day 10 出现第一种缺乏病信号 |
| 水合 | 半天不喝水就口渴；高温战斗 1–2 小时必须补水 |
| 环境 | 雨季湿衣赶路有真实失温风险；高温高湿下硬刚会中暑 |
| 训练 | 空腹练=白练；连续肝训练=过度训练 |

### 3.2 正反馈（Reward）

| 行为 | 奖励体感 |
|---|---|
| 微量全达标 | 耐力恢复 ×1.15、体力上限 +5% |
| 训练后 4h 内补蛋白 | 经验收益 ×1.5 |
| 水合满 + 热量盈余 | 训练成长加速 |
| 7 天评分稳定 | 状态图标全绿，无任何 debuff |

### 3.3 节奏（Pacing）

| 阶段 | 时间 | 设计目标 |
|---|---|---|
| 开荒适应 | day 1–7 | 宽限期，不发病，让玩家读 UI |
| 第一波压力 | day 10–14 | 坏血病首发（罐头党陷阱） |
| 中期多线 | day 20–30 | 贫血 / 电解质紊乱开始出现 |
| 长期经营 | day 40+ | 骨质流失 / 夜盲症等慢病浮现 |

## 4. 逐项调优目标

### 4.1 微量营养素 DRI

**原则**：核心循环相关的营养素调紧，背景病保持现实值。

| 营养素 | 现实 DRI | 建议游戏值 | 调整方向 | 理由 |
|---|---|---|---|---|
| 维C | 100 mg | **80 mg** | ↓ 调低阈值 | 罐头经济核心压力源，坏血病是招牌病 |
| 钠 | 2000 mg | **1800 mg** | ↓ 略调 | 高温出汗即缺，电解质紊乱急性事件钩子 |
| 维D | 15 µg | **10 µg** | ↓ 调低 | 迫使玩家出门晒太阳，禁止"宅家流" |
| 钾 | 3000 mg | 3000 mg | 保持 | 与钠联动，背景病 |
| 钙 | 1000 mg | 1000 mg | 保持 | 骨质流失慢病原 |
| 铁 | 15 mg | 15 mg | 保持 | 贫血慢病原 |
| 维A | 900 µg | 900 µg | 保持 | 夜盲症慢病原 |
| B1 | 1.2 mg | 1.2 mg | 保持 | 脚气病慢病原 |

### 4.2 热量档（TDEE）

**原则**：匹配 PZ 食物经济，调到"正常吃刚好，高强度会饿"。

| 活动档 | 现实值 | 建议初值 | 调优方法 |
|---|---|---|---|
| 静息 | 2000 | **1800** | 先跑仿真，看"正常搜刮流"日均摄入 |
| 中度 | 2700 | **2400** | 调到"正常吃刚好维持" |
| 高强度 | 3400 | **3000** | 调到"必须多吃否则掉体重" |

> 验证标准：均衡派玩家日均摄入 ≈ 中度档 ±10%，体重稳定。

### 4.3 水合衰减与阈值

**阈值保持**：100–60 正常 / 60–40 口渴 / 40–20 耐力↓ / <20 崩溃。

**衰减速率目标体感**：

| 场景 | 降到 60 的时间 | 降到 40 的时间 |
|---|---|---|
| 静息 / 睡觉 | — | 一晚掉 20–30 |
| 正常活动（步行/搜刮） | 6–8 游戏小时 | 10–12 小时 |
| 高温 + 高湿 | 3–4 小时 | 6–8 小时 |
| 高强度战斗/冲刺 | 1–2 小时 | 3–4 小时 |

**利尿叠加**：酒精、咖啡因按 Config 系数加速衰减；啤酒净补水 ≈ 0 或微负。

### 4.4 动作强度档

**相对梯度保持**：1.0 / 1.4 / 2.0 / 4.0 / 7.0（冲刺 ≈ 7× 静息，符合现实）。

**联调目标**：
- 冲刺（7.0）耐力消耗要狠——连续冲刺 30 秒见底，逼玩家切走路烧脂肪。
- 跑步（4.0）碳水消耗主导，糖原耗尽后耐力断崖。
- 步行/蹲走（1.4–2.0）脂肪主导，可持续。

**钠钾出汗流失**：与强度 × 温度 × 湿度联动，高强度+高温 = 大量失钠。

### 4.5 食物降解

| 营养素 | 现实参考 | 游戏目标 |
|---|---|---|
| 维C | 3–5 天显著下降 | **3 天明显，7 天接近归零**（制造新鲜供应链压力） |
| 维A / B1 | 周级缓慢 | 7–10 天开始下降，30 天减半 |
| 矿物质 | 极慢 | 保质期内 100%（保持） |

**储存系数**：冷藏 ×0.3、冷冻暂停、罐头锁定——保持。

**验证**：只吃罐头的玩家 day 10 左右 VC 7 天均值 < 阈值 → 坏血病。

### 4.6 饮品药效

| 类别 | 补水系数 | 目标体感 |
|---|---|---|
| 白水 | 1.0 | 基准 |
| 汽水/果汁 | ~0.85 | 糖多但不解渴，越喝越想喝 |
| 咖啡/浓茶 | ~0.9 | 短时抗疲劳但之后疲劳反弹，利尿 |
| 啤酒 | ≈ 0 或微负 | "拿啤酒当水喝"会脱水 + 醉酒 + 失温风险 |
| 烈酒 | 负 | 净脱水明显 |

### 4.7 疾病触发节奏（N 天分层）

**原则**：急性/常见病快，慢/背景病慢，不能一刀切。

| 疾病 | 缺乏 | 建议触发 N 天（7天均值<阈值） | 恢复 M 天 |
|---|---|---|---|
| 坏血病 | 维C | **5–7 天** | 3–5 天 |
| 电解质紊乱 | 钠/钾 | **3–5 天**（急性） | 1–2 天（补盐即缓） |
| 贫血 | 铁 | 10–14 天 | 7–10 天 |
| 消瘦 | 蛋白 | 10–14 天 | 7–10 天 |
| 夜盲症 | 维A | 14–21 天 | 10–14 天 |
| 脚气病 | B1 | 14–21 天 | 10–14 天 |
| 骨质流失 | 维D/钙 | 21–30 天 | 14–21 天 |

**宽限期**：新开档 7–10 天不发病（让玩家适应 UI）。

### 4.8 训练成长

| 参数 | 建议值 | 体感 |
|---|---|---|
| 蛋白窗口 | 4 游戏小时 | 练完赶紧吃，有紧迫感 |
| 窗口内经验倍率 | **×1.5** | 明显变强，正反馈 |
| 空腹训练经验惩罚 | **×0.3** | "空腹练=白练"可感知 |
| 过度训练触发 | 连续 3 天高负荷恢复不足 | 防止肝训练刷级 |
| 过度训练惩罚 | 成长 ×0.5、疲劳加速 | 强迫休息 |
| 微量全达标耐力恢复 | **×1.15** | 吃好有爽感 |

## 5. 调优方法论（画像仿真）

### 5.1 定义玩家画像

| 画像 | 行为特征 | 预期结果 |
|---|---|---|
| 🥫 罐头党 | 只吃罐头，不碰新鲜蔬果 | day 10 左右坏血病 |
| 🥗 均衡派 | 新鲜蔬果 + 肉 + 主食均衡 | 不发病，评分稳定 |
| 💪 高运动战士 | 大量训练 + 蛋白管理 | 成长快，但若忽略水合/钠则电解质紊乱 |
| 🌧️ 雨季赶路 | 湿衣 + 低温 + 长途 | 失温 + 消瘦 |
| 🍺 酗酒流 | 啤酒当水喝 | 反复脱水 + 失温 + 消瘦 |

### 5.2 仿真流程

```
1. 用 debug 工具喂食/给水/设天气/跳天，模拟画像行为 30–60 天
2. 记录：发病时间、急性事件频率、评分曲线、体重/耐力趋势
3. 对照 §3 目标体感，逐项调整 RM_Config.lua
4. 实机手感微调（时间感、UI 反馈节奏）
```

### 5.3 验证清单

- [ ] 罐头党：day 10 前后出现坏血病前兆
- [ ] 均衡派：30 天不发病，7 天评分稳定在 0.8+
- [ ] 高运动战士：蛋白窗口内补蛋白 = 经验明显放大
- [ ] 雨季赶路：湿衣低温 1–2 小时内出现失温前兆
- [ ] 酗酒流：啤酒补水后水合仍持续下降
- [ ] 高温战斗：大量出汗后猛灌水 → 水合正常但血钠低 → 电解质紊乱

## 7. M4 验收标准

1. **画像仿真全部通过**：5 种画像行为符合 §5.3 预期。
2. **压迫感达标**：正常玩家不能忽略营养/水合/环境，否则 day 10–14 必有惩罚。
3. **正反馈达标**：吃好+练好的玩家能明显感受到耐力↑、经验↑、无 debuff。
4. **因果可推理**：玩家能从症状反推出原因（坏血病→缺 VC→吃新鲜蔬果）。
5. **可调性**：所有平衡系数集中在 `RM_Config.lua`，改参数不改逻辑。
6. **性能**：平均 < 0.2ms/帧，不影响原版流畅度。
