📦 原版游戏
✨ 装了 MOD 之后
🍔
只算 4 种东西 热量、碳水、蛋白、脂肪
吃多了变胖，吃少了变瘦
🥗
算 4 + 8 种东西 多了：钠、钾、钙、铁、维A、维C、维D、维B1
缺哪种得哪种病
💧
喝水只是解渴 渴了喝水，不渴不管
喝啥都一样
🥤
喝水有讲究 白水补水，运动饮料补电解质
咖啡利尿，喝酒越喝越渴
🏃
运动只掉耐力 跑累了喘气，歇会儿就好
练多了自动升级力量/体能
💪
运动要看身体状态 猛跑烧糖，慢跑烧脂肪
练完要补蛋白+睡觉才长肌肉
硬练会受伤（过度训练）
🌧️
天气只影响心情 太冷会感冒，下雨不爽
但不会直接搞垮身体
🌡️
天气真能搞死人 大热天跑 → 中暑、抽筋
大冷天湿身 → 失温
不喝水 → 脱水崩溃
🤒
生病只有感冒/僵尸感染 和吃啥基本没关系
🏥
缺营养会得 7 种病 缺维C → 坏血病（牙龈出血）
缺铁 → 贫血（头晕没劲）
缺钙 → 骨质疏松（容易骨折）……
📦
食物只有"新鲜/腐烂" 营养永远不变
放一年的苹果和刚摘的一样补
🍎
营养会流失 维C流失最快（几天就没了）
矿物质最稳定（能存很久）
所以罐头不如新鲜果蔬
🎯 一句话总结：原版只算"饱不饱"，MOD 算"吃得好不好、练得对不对、扛不扛得住天气"。

🆕 MOD 全新增加的东西（原版完全没有）

8 种微量营养素钠、钾、钙、铁、维生素 A/C/D/B1
水合池身体含水量 0~100%，缺水会崩溃
7 种营养病坏血病、贫血、电解质紊乱、消瘦、夜盲、脚气病、骨质流失
4 种急性事件热抽筋、中暑、失温、脱水崩溃
燃料模型高强度烧糖、低强度烧脂肪、空腹更耗脂肪
训练恢复系统练完要补蛋白+睡觉才长肌肉，硬练会过度训练
饮品药效白水/运动饮料/咖啡/茶/酒 效果各不同
食物营养降解放久了维生素流失，矿物质稳定
环境微气候温度、湿度、湿度叠加影响身体
专用 UI 面板用 NeatUI 做的身体状态仪表盘
