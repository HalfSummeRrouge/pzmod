🚗 Real Metabolism

一个让僵尸末日里的"吃饭运动"变真实的 MOD
🎯 一句话：它让你的角色像真人一样，吃啥、动啥、天气咋样，都会影响身体状态。

🧠 打个比方

把你的角色想象成一辆汽车🚗：

• 吃东西 = 加油 + 加机油 + 加冷却液（光加一种不够！）
• 跑步打架 = 踩油门（猛踩费油，慢慢开省油）
• 下雨天/大太阳 = 天气（冬天费电，夏天怕过热）
• 缺营养 = 车坏了（没机油→发动机磨损，没冷却液→开锅）

🖼️ 它管哪三件事？

⚙️ 它怎么工作的？

💡 MOD 只读游戏的身体数据，然后"乘以一个系数"来微调，
不会强行改掉游戏本身的逻辑（就像给车装个仪表盘，不是换发动机）。

📖 举个栗子

😰 你天天吃罐头，从不喝水，大太阳下跑了半小时……

→ 身体判定：维生素C不够 + 脱水 + 过热
→ 结果：抽筋 / 中暑 / 牙龈出血（坏血病）

😎 但如果你吃蔬菜水果、喝水、累了就歇着……

→ 身体判定：营养均衡 + 休息充足
→ 结果：跑步更久，力气变大

🎯 它就是让你在僵尸末日里，
真的要"好好吃饭、好好休息、注意天气"才能活得好。
